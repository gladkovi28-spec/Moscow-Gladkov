# Habit Tracker

Десктоп-приложение для отслеживания привычек на PyQt6 и SQLite.
Пользователь заводит привычки, ежедневно отмечает их выполнение
и видит прогресс: серии «подряд», процент за месяц и календарную
сетку активности в стиле GitHub.

## Возможности
- добавление привычек с частотой (ежедневно или N раз в неделю) и цветом
- отметка выполнения за сегодня и за любой прошедший день
- подсчёт текущей серии и личного рекорда
- статистика за текущий месяц и график выполнения
- календарная сетка прогресса за 8 недель
- экспорт истории отметок в CSV
- архивация привычек без удаления данных

## Целевая аудитория
Все, кто хочет выработать регулярные привычки и видеть прогресс наглядно.

## Запуск
pip install -r requirements.txt
python main.py

## Стек
Python 3.11, PyQt6, sqlite3 (стандартный модуль), matplotlib

## Структура проекта
- database.py — схема БД и все SQL-запросы
- stats.py — расчёт серий и процентов
- ui/ — главное окно, диалоги и виджеты
- main.py — точка входа
